## Local/generated evidence

Vanilla/rules/cache state, tool reports, deployment hashes/backups, native
timestamp/nonce work profiles, raw logs/saves/screenshots and private history remain
in their existing ignored tool output or .local. Current storage namespaces include
brittany_missions, brittany_runtime, brittany_nantes_manual and american_runtime;
the latter aliases do not define new source mods. Never apply published ownership
records to live processes. Existing current/latest/baseline pointers are local
operational state, not historical certification for another source/build.

Future reviewed evidence may use `docs/testing/framework/<scenario>/` or
`docs/testing/mods/<source-id>/<scenario>/` after independent review. This phase
creates no such bundles and moves none of the old ones. Raw material remains local;
per-mod testing directories contain coverage/scenario narratives, not raw saves.
The historical JSON redaction manifest retains old hashes; later documentation
hashes/mapping belong exclusively to the separate migration manifest.
