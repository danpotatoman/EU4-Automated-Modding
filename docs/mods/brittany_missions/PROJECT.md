# Brittany Missions project

Owner: mod/brittany_missions
Last updated: 2026-10-06 (documentation ownership only)

Source: `mod/brittany_missions/`. This independent mod targets Brittany (BRI),
with missions, three triggered events, a review decision, modifiers, constitutional
government reform, permanent power projection, a preview trigger and two conditional
reward effects. The comment-only `missions/Breton_Missions.txt` replaces vanilla's
file; custom content is in `missions/Custom_Breton_Missions.txt`.

Seven series comprise five main columns and two mutually exclusive diplomatic
series sharing column 1 rows 11-13. Six series explicitly exclude random-map setup;
slot 4 only checks BRI, and random-map support is unverified. Production calls
installed vanilla helpers; installed files are external read-only dependencies.
The source currently has 11 files and no release descriptor. Development descriptors
are generated by shared tooling; neither generation nor static acceptance certifies
export readiness.

Read [status](STATUS.md), [design](DESIGN.md), [roadmap](ROADMAP.md),
[decisions](DECISIONS.md) and [testing](testing/README.md) for supported claims.
The [shared tooling](../../TESTING.md) stages isolated byte-preserving copies with
test-only hooks; framework recovery/input results have different coverage from
Brittany's gameplay. Substantial tasks follow [plans](../../../.agent/PLANS.md).

Development metadata and inspector scenarios/rules belong to
[this mod's config](../../../tools/mods/brittany_missions/config.json), with
[shared reader/legacy rules](../../runtime/configuration-ownership.md). Native
fixture aliases and labels remain separate contract bindings. Gameplay is unchanged.
