# American Century project

Owner: mod/american_century
Last updated: 2026-10-06 (documentation ownership only)

Source: `mod/american_century/`; identifier prefix `amc_`. This independent
project has an adopted USA mission design and English colonial runway. It preserves
England's DLC mission grids and unchanged vanilla USA formation, replacing only
the vanilla USA mission file through a comment-only override and custom series.

The first bounded slice has nine USA missions, three colonial-origin missions,
two additive preparation decisions, a two-option constitution event, twelve named
modifiers and English localisation. Nine source files include eight gameplay/
localisation files and a descriptor; the runtime runner rewrites the descriptor,
so recorded native evidence does not validate the source release descriptor.
The designed 55-USA-mission tree is not fully implemented.

Read [status](STATUS.md), [design](DESIGN.md), [roadmap](ROADMAP.md),
[decisions](DECISIONS.md) and [testing](testing/README.md). The active
[American Century plan](../../../.agent/plans/2026-10-04-american-century.md)
retains its prior design/implementation authorization. Tooling is shared with
Brittany; a Brittany regression is dependency protection, not USA coverage.
[Vanilla provenance](vanilla-provenance.json) identifies selected installed references,
not a general claim of compatible versions/DLC or natural campaign verification.

Development metadata and inspector scenarios/rules belong to
[this mod's config](../../../tools/mods/american_century/config.json), with
[shared reader/legacy rules](../../runtime/configuration-ownership.md). The current
development name stays `american_century (Development)`; native fixture labels and
source release descriptor are separate. Gameplay is unchanged.
