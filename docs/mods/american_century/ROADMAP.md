Owner: mod/american_century

[execution plan](../../../.agent/plans/2026-10-04-american-century.md). This migration
does not expand gameplay authorization or start the next gameplay phase.

   or independence -> USA assignment, origin missions/rewards and saved flags.
2. Alternate Local Guarantees -> Union claims/rewards/paused reload are now proved
   in the [bounded fixture](../../testing/mods/american_century/local-guarantees-2026-10-07/README.md).

   and rewards, military/naval roots, war/formation refusal, repeat-click, elapsed
   annual accrual and timed expiry. The building transition is the next logical
   bounded task; this session stops after constitutional evidence.
3. Expand continental/native diplomacy and industry/institutions branch by branch;
   then naval/hemispheric, military/global capstones toward the adopted 55-mission tree.
4. Integrated campaign/tree, balance, AI, version/DLC and release/deployment checks
   remain separate evidence work, not inferred from the first fixture slice.

Use the existing [six detailed playtests](../../testing/american-century/README.md#playtest-list)
and [coverage](testing/coverage.md). Shared input/timeouts/recovery are framework
dependencies; successes from another mod do not close these gameplay items.
